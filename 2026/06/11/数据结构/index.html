总结

算法 核心思想 复杂度
归并排序 分治 + 合并有序数组 O(NlogN)
快速排序 分区 + 随机 pivot O(NlogN)
堆排序 大根堆 + 交换调整 O(NlogN)
基数排序 按位桶排序 O(N)
二叉树遍历 递归 / 栈模拟 O(N)
前缀树 多叉树存储前缀 O(L)
BFS/DFS 队列 / 栈遍历 O(V+E)
Kruskal 并查集 + 边排序 O(ElogE)
Prim 小根堆 + 贪心扩展 O(ElogV)
Dijkstra 贪心选择最近点 O(V²) 或 O(ElogV)
