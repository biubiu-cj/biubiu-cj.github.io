## 一、排序算法

### 1.1 归并排序（O(NlogN)）

```java
public class MergeSort {
    public static void mergeSort(int[] arr) {
        if (arr == null || arr.length < 2) return;
        process(arr, 0, arr.length - 1);
    }

    private static void process(int[] arr, int L, int R) {
        if (L == R) return;
        int mid = L + ((R - L) >> 1);
        process(arr, L, mid);
        process(arr, mid + 1, R);
        merge(arr, L, mid, R);
    }

    private static void merge(int[] arr, int L, int M, int R) {
        int[] help = new int[R - L + 1];
        int p1 = L, p2 = M + 1, i = 0;
        while (p1 <= M && p2 <= R) {
            help[i++] = arr[p1] <= arr[p2] ? arr[p1++] : arr[p2++];
        }
        while (p1 <= M) help[i++] = arr[p1++];
        while (p2 <= R) help[i++] = arr[p2++];
        for (i = 0; i < help.length; i++) arr[L + i] = help[i];
    }
}
```

**小和问题**：求数组中每个数左边比它小的数的总和，可利用归并排序思想。

```java
public class SmallSum {
    public static int smallSum(int[] arr) {
        if (arr == null || arr.length < 2) return 0;
        return process(arr, 0, arr.length - 1);
    }

    private static int process(int[] arr, int L, int R) {
        if (L == R) return 0;
        int mid = L + ((R - L) >> 1);
        return process(arr, L, mid) + process(arr, mid + 1, R) + merge(arr, L, mid, R);
    }

    private static int merge(int[] arr, int L, int M, int R) {
        int[] help = new int[R - L + 1];
        int p1 = L, p2 = M + 1, i = 0, res = 0;
        while (p1 <= M && p2 <= R) {
            res += arr[p1] < arr[p2] ? arr[p1] * (R - p2 + 1) : 0;
            help[i++] = arr[p1] < arr[p2] ? arr[p1++] : arr[p2++];
        }
        while (p1 <= M) help[i++] = arr[p1++];
        while (p2 <= R) help[i++] = arr[p2++];
        for (i = 0; i < help.length; i++) arr[L + i] = help[i];
        return res;
    }
}
```

### 1.2 快速排序

```java
public class QuickSort {
    public static void quickSort(int[] arr) {
        if (arr == null || arr.length < 2) return;
        quickSort(arr, 0, arr.length - 1);
    }

    private static void quickSort(int[] arr, int L, int R) {
        if (L >= R) return;
        swap(arr, L + (int)(Math.random() * (R - L + 1)), R);
        int[] p = partition(arr, L, R);
        quickSort(arr, L, p[0] - 1);
        quickSort(arr, p[1] + 1, R);
    }

    private static int[] partition(int[] arr, int L, int R) {
        int less = L - 1, more = R, i = L;
        while (i < more) {
            if (arr[i] < arr[R]) swap(arr, ++less, i++);
            else if (arr[i] > arr[R]) swap(arr, --more, i);
            else i++;
        }
        swap(arr, more, R);
        return new int[]{less + 1, more};
    }

    private static void swap(int[] arr, int i, int j) {
        int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
    }
}
```

### 1.3 堆排序

```java
public class HeapSort {
    public static void heapSort(int[] arr) {
        if (arr == null || arr.length < 2) return;
        for (int i = arr.length / 2 - 1; i >= 0; i--) {
            heapify(arr, i, arr.length);
        }
        for (int i = arr.length - 1; i > 0; i--) {
            swap(arr, 0, i);
            heapify(arr, 0, i);
        }
    }

    private static void heapify(int[] arr, int index, int heapSize) {
        int left = 2 * index + 1;
        while (left < heapSize) {
            int largest = (left + 1 < heapSize && arr[left + 1] > arr[left])
                    ? left + 1 : left;
            largest = arr[largest] > arr[index] ? largest : index;
            if (largest == index) break;
            swap(arr, largest, index);
            index = largest;
            left = 2 * index + 1;
        }
    }

    private static void swap(int[] arr, int i, int j) {
        int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
    }
}
```

### 1.4 基数排序

```java
public class RadixSort {
    public static void radixSort(int[] arr) {
        if (arr == null || arr.length < 2) return;
        int max = Arrays.stream(arr).max().getAsInt();
        int maxBits = 0;
        while (max != 0) { maxBits++; max /= 10; }
        radixSort(arr, 0, arr.length - 1, maxBits);
    }

    private static void radixSort(int[] arr, int L, int R, int digit) {
        final int radix = 10;
        int[] bucket = new int[R - L + 1];
        for (int d = 1; d <= digit; d++) {
            int[] count = new int[radix];
            for (int i = L; i <= R; i++) count[getDigit(arr[i], d)]++;
            for (int i = 1; i < radix; i++) count[i] += count[i - 1];
            for (int i = R; i >= L; i--) {
                int j = getDigit(arr[i], d);
                bucket[count[j] - 1] = arr[i];
                count[j]--;
            }
            for (int i = L, j = 0; i <= R; i++, j++) arr[i] = bucket[j];
        }
    }

    private static int getDigit(int x, int d) {
        return (Math.abs(x) / (int)Math.pow(10, d - 1)) % 10;
    }
}
```

```java
public class LinkedListOps {
    // 反转链表
    public ListNode reverse(ListNode head) {
        ListNode prev = null, cur = head;
        while (cur != null) {
            ListNode next = cur.next;
            cur.next = prev;
            prev = cur;
            cur = next;
        }
        return prev;
    }

    // 快慢指针判断环
    public boolean hasCycle(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) return true;
        }
        return false;
    }

    // 合并有序链表
    public ListNode merge(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0), cur = dummy;
        while (l1 != null && l2 != null) {
            if (l1.val <= l2.val) { cur.next = l1; l1 = l1.next; }
            else { cur.next = l2; l2 = l2.next; }
            cur = cur.next;
        }
        cur.next = (l1 != null) ? l1 : l2;
        return dummy.next;
    }
}
```

```java
public void inorderIter(TreeNode root) {

    while (!stk.isEmpty() || root != null) {
        if (root != null) {
            stk.push(root);
            root = root.left;

            root = stk.pop();

            root = root.right;
        }
    }

public void postorderIter(TreeNode root) {

    stk1.push(root);
    while (!stk1.isEmpty()) {
        TreeNode node = stk1.pop();
        stk2.push(node);
        if (node.left != null) stk1.push(node.left);
        if (node.right != null) stk1.push(node.right);
```

```java
// 二叉树最大宽度
public int maxWidth(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> q = new LinkedList<>();
    Map<TreeNode, Integer> levelMap = new HashMap<>();
    q.offer(root);
    levelMap.put(root, 1);
    int curLevel = 1, curCnt = 0, max = 0;
    while (!q.isEmpty()) {
        TreeNode cur = q.poll();
        int nodeLevel = levelMap.get(cur);
        if (nodeLevel == curLevel) {
            curCnt++;
        } else {
            max = Math.max(max, curCnt);
            curLevel++;
            curCnt = 1;
        }
        if (cur.left != null) {
            levelMap.put(cur.left, nodeLevel + 1);
            q.offer(cur.left);
        }
        if (cur.right != null) {
            levelMap.put(cur.right, nodeLevel + 1);
            q.offer(cur.right);
        }
    }
    return Math.max(max, curCnt);
}
```

### 3.6 判断平衡二叉树

```java
class ReturnType {
    boolean isBalanced;
    int height;
    ReturnType(boolean b, int h) { isBalanced = b; height = h; }
}

public boolean isBalanced(TreeNode root) {
    return check(root).isBalanced;
}

private ReturnType check(TreeNode root) {
    if (root == null) return new ReturnType(true, 0);
    ReturnType left = check(root.left);
    ReturnType right = check(root.right);
    int height = Math.max(left.height, right.height) + 1;
    boolean ok = left.isBalanced && right.isBalanced
            && Math.abs(left.height - right.height) <= 1;
    return new ReturnType(ok, height);
}
```

### 3.7 最低公共祖先（LCA）

```java
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root;
    return left != null ? left : right;
}
```

```java
public class Serializer {
    // 先序序列化
    public String serialize(TreeNode root) {
        if (root == null) return "#_";
        return root.val + "_" + serialize(root.left) + serialize(root.right);
    }

    // 先序反序列化
    public TreeNode deserialize(String data) {
        Queue<String> q = new LinkedList<>(Arrays.asList(data.split("_")));
        return build(q);
    }

    private TreeNode build(Queue<String> q) {
        String val = q.poll();
        if ("#".equals(val)) return null;
        TreeNode node = new TreeNode(Integer.parseInt(val));
        node.left = build(q);
        node.right = build(q);
        return node;
    }
}
```

## 四、前缀树（Trie）

```java
public class Trie {
    static class TrieNode {
        int pass = 0;
        int end = 0;
        TrieNode[] nexts = new TrieNode[26];
    }

    private TrieNode root = new TrieNode();

    public void insert(String word) {
        TrieNode node = root;
        node.pass++;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.nexts[idx] == null) node.nexts[idx] = new TrieNode();
            node = node.nexts[idx];
            node.pass++;
        }
        node.end++;
    }

    public int search(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.nexts[idx] == null) return 0;
            node = node.nexts[idx];
        }
        return node.end;
    }

    public int prefixCount(String pre) {
        TrieNode node = root;
        for (char c : pre.toCharArray()) {
            int idx = c - 'a';
            if (node.nexts[idx] == null) return 0;
            node = node.nexts[idx];
        }
        return node.pass;
    }

    public void delete(String word) {
        if (search(word) == 0) return;
        TrieNode node = root;
        node.pass--;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (--node.nexts[idx].pass == 0) {
                node.nexts[idx] = null;
                return;
            }
            node = node.nexts[idx];
        }
        node.end--;
    }
}
```

```java
// BFS
public void bfs(Node start) {
    Queue<Node> q = new LinkedList<>();
    Set<Node> visited = new HashSet<>();
    q.offer(start);
    visited.add(start);
    while (!q.isEmpty()) {
        Node cur = q.poll();
        System.out.println(cur.value);
        for (Node next : cur.nexts) {
            if (!visited.contains(next)) {
                visited.add(next);
                q.offer(next);
            }
        }
    }
}

// DFS（栈模拟，保留路径信息）
```

### 5.3 拓扑排序

```java
public List<Node> topologicalSort(Graph graph) {
    Map<Node, Integer> inMap = new HashMap<>();
    Queue<Node> zeroInQueue = new LinkedList<>();
    for (Node node : graph.nodes.values()) {
        inMap.put(node, node.in);
        if (node.in == 0) zeroInQueue.offer(node);
    }
    List<Node> result = new ArrayList<>();
    while (!zeroInQueue.isEmpty()) {
        Node cur = zeroInQueue.poll();
        result.add(cur);
        for (Node next : cur.nexts) {
            inMap.put(next, inMap.get(next) - 1);
            if (inMap.get(next) == 0) zeroInQueue.offer(next);
        }
    }
    return result;
}
```

### 5.4 最小生成树 — Kruskal

```java
class UnionFind {
    Map<Node, Node> father = new HashMap<>();
    UnionFind(List<Node> nodes) {
        for (Node n : nodes) father.put(n, n);
    }
    Node find(Node n) {
        if (father.get(n) != n) father.put(n, find(father.get(n)));
        return father.get(n);
    }
    boolean isSameSet(Node a, Node b) { return find(a) == find(b); }
    void union(Node a, Node b) { father.put(find(a), find(b)); }
}

public Set<Edge> kruskal(Graph graph) {
    List<Node> nodeList = new ArrayList<>(graph.nodes.values());
    UnionFind uf = new UnionFind(nodeList);
    PriorityQueue<Edge> pq = new PriorityQueue<>((a, b) -> a.weight - b.weight);
    pq.addAll(graph.edges);
    Set<Edge> result = new HashSet<>();
    while (!pq.isEmpty()) {
        Edge e = pq.poll();
        if (!uf.isSameSet(e.from, e.to)) {
            result.add(e);
            uf.union(e.from, e.to);
        }
    }
    return result;
}
```

### 5.5 最小生成树 — Prim

```java
public Set<Edge> prim(Graph graph) {
    PriorityQueue<Edge> pq = new PriorityQueue<>((a, b) -> a.weight - b.weight);
    Set<Node> visited = new HashSet<>();
    Set<Edge> result = new HashSet<>();
    for (Node node : graph.nodes.values()) {
        if (!visited.contains(node)) {
            visited.add(node);
            pq.addAll(node.edges);
            while (!pq.isEmpty()) {
                Edge e = pq.poll();
                if (!visited.contains(e.to)) {
                    visited.add(e.to);
                    result.add(e);
                    pq.addAll(e.to.edges);
                }
            }
        }
    }
    return result;
}
```

### 5.6 Dijkstra 最短路径

```java
public Map<Node, Integer> dijkstra(Node start) {
    Map<Node, Integer> dist = new HashMap<>();
    Set<Node> settled = new HashSet<>();
    dist.put(start, 0);
    Node cur = getMinDistNode(dist, settled);
    while (cur != null) {
        int d = dist.get(cur);
        for (Edge e : cur.edges) {
            Node to = e.to;
            if (!dist.containsKey(to)) dist.put(to, d + e.weight);
            else dist.put(to, Math.min(dist.get(to), d + e.weight));
        }
        settled.add(cur);
        cur = getMinDistNode(dist, settled);
    }
    return dist;
}

private Node getMinDistNode(Map<Node, Integer> dist, Set<Node> settled) {
    Node minNode = null;
    int minDist = Integer.MAX_VALUE;
    for (Map.Entry<Node, Integer> e : dist.entrySet()) {
        if (!settled.contains(e.getKey()) && e.getValue() < minDist) {
            minNode = e.getKey();
            minDist = e.getValue();
        }
    }
    return minNode;
}
```

## 六、贪心算法

### 6.1 安排最多会议

按结束时间排序，每次选择最早结束且不冲突的会议。

```java
class Meeting {
    int start, end;
    Meeting(int s, int e) { start = s; end = e; }
}

public int maxMeetings(Meeting[] meetings) {
    Arrays.sort(meetings, (a, b) -> a.end - b.end);
    int count = 1, lastEnd = meetings[0].end;
    for (int i = 1; i < meetings.length; i++) {
        if (meetings[i].start >= lastEnd) {
            count++;
            lastEnd = meetings[i].end;
        }
    }
    return count;
}
```

### 6.2 切金条（哈夫曼编码）

用小根堆，每次取最小的两个合并。

```java
public int minCost(int[] arr) {
    PriorityQueue<Integer> pq = new PriorityQueue<>();
    for (int x : arr) pq.offer(x);
    int total = 0;
    while (pq.size() > 1) {
        int a = pq.poll(), b = pq.poll();
        total += a + b;
        pq.offer(a + b);
    }
    return total;
}
```

## 总结

| 算法 | 核心思想 | 复杂度 |
|---|---|---|
| 归并排序 | 分治 + 合并有序数组 | O(NlogN) |
| 快速排序 | 分区 + 随机 pivot | O(NlogN) |
| 堆排序 | 大根堆 + 交换调整 | O(NlogN) |
| 基数排序 | 按位桶排序 | O(N) |
| 二叉树遍历 | 递归 / 栈模拟 | O(N) |
| 前缀树 | 多叉树存储前缀 | O(L) |
| BFS/DFS | 队列 / 栈遍历 | O(V+E) |
| Kruskal | 并查集 + 边排序 | O(ElogE) |
| Prim | 小根堆 + 贪心扩展 | O(ElogV) |
| Dijkstra | 贪心选择最近点 | O(V²) 或 O(ElogV) |
